Introduction

Accessible design begins with understanding who we need to make our app accessible for. Our app should probably be accessible to all potential users so we want to make it compatible with screen readers, we want to make the text size large enough for visual impairments, we want to make it so the website is tabbable for issues with mobility and so much more. Once we understand the different ways we need to make our website accessible we can begin to create it.

Meaningful Structure

We can use meaningful structure with html, building appropriate headings in logical order, labeling everything properly and including aria labels when appropriate to give accessible names, and have a skip to the main content section. We need to make sure we are following the guidelines for accessible forms and data tables. If we have an image or video included in our website we should write meaningful alternate text (captions) and add an option for subtitles to our videos. When users zoom in on a page all of the content should remain accessible to the user. We can avoid using divs instead of appropriate semantic elements and other unclear structures and test our structure with programs like html5 outliner.

Design Choices

We can also make sure our design choices are accessible. We can make font sizes large enough, use enough color contrast, use icons that people will understand, and make sure button sizes are large enough. Everything should be navigable by a keyboard and we should test our websites on screen readers to see if they are understandable. Our website should have keyboard focus so users can see where they are on our website.

Testing

When we have completed all of these we can test to see how accessible our website is with an extension like silktide or wave. It is also very helpful to be able to test with individuals who do use assistive technologies or have disabilities to see if they can interact well with your page.

Quick Lists on How to Make Your Website More Accessible

Design Choices

  • Increase font size
  • Improve color contrast
  • Use icons that people will understand
  • Increase button size and clickable area size
  • Make the website keyboard navigable
  • Maintain readability when users zoom in

Meaningful Structure

  • Use meaningful structure in HTML
  • Build appropriate heading hierarchies
  • Use proper labels and ARIA labels where appropriate
  • Include a skip-to-main-content link
  • Use appropriate semantic HTML elements
  • Provide alternative text for images
  • Include captions on videos

Testing Tools

  • HTML5 Outliner
  • Silktide
  • WAVE Accessibility Evaluation Tool
  • Adobe Color Contrast Checker
  • Test the website with potential users who have accessibility needs
